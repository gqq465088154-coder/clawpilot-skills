技能详情 · Skill Cards

🔗
clawpilot-pair
安装 / 升级 ClawPilot，验证主机运行时就绪状态，生成 PocketClaw 配对码。
CLI 入口： clawpilot pair --runtime <openclaw|hermes>
安装命令： npm i -g @rethinkingstudio/clawpilot@latest
  1. 安装 / 升级 ClawPilot
  2. 检测目标运行时（openclaw / hermes）
  3. 运行时就绪检查（auth、gateway 可达性）
  4. 生成配对码并输出
📤
clawpilot-send
将本地或生成的文件发送回 PocketClaw 移动端，自动处理上传、路由和消息投递。
CLI 入口： clawpilot send "/absolute/path/to/file"
双运行时： clawpilot send --runtime <oc|hm> "/path"
  1. 确认会话为 PocketClaw / Relay
  2. 解析绝对文件路径
  3. 检测运行时并选择路由
  4. 调用 clawpilot send 完成投递
🩺
clawpilot-doctor
诊断和修复 ClawPilot / OpenClaw 主机问题：状态检查、日志、重启、更新、自修复。
状态检查： clawpilot status
重启服务： clawpilot restart
  1. 执行最小化诊断操作
  2. 报告检查项的通过 / 失败
  3. 给出下一步修复命令
  4. 验证修复结果
⚙️
clawpilot-config
定位、验证并最小化修复 ClawPilot / OpenClaw 网关配置（token、密码、环境变量）。
配置路径： ~/.config/openclaw/config.yaml
检查项： gateway_token · password · env vars
  1. 定位配置文件
  2. 检查 auth 相关字段
  3. 验证环境变量引用是否存在
  4. 报告缺失项并提出最小修复

部署指南 · Deployment

🚀 快速开始

# 1. 安装 ClawPilot CLI
npm install -g @rethinkingstudio/clawpilot@latest

# 2. 选择运行时并配对
clawpilot pair --runtime openclaw
# 或
clawpilot pair --runtime hermes

# 3. 验证状态
clawpilot status

🌐 OpenClaw 运行时

# 确认 OpenClaw 配置存在
cat ~/.config/openclaw/config.yaml

# 验证 Gateway Auth
curl -s http://localhost:3000/health

# 配对
clawpilot pair --runtime openclaw

⚡ Hermes 运行时

# 安装 Hermes Gateway
hermes gateway install
hermes gateway start

# 验证 Hermes 状态
hermes gateway status

# 配对
clawpilot pair --runtime hermes

📤 文件投递

# 单运行时（自动检测）
clawpilot send "/path/to/file.pdf"

# 指定运行时（双运行时主机）
clawpilot send --runtime openclaw "/path/to/file.pdf"
clawpilot send --runtime hermes "/path/to/file.pdf"

# 文件大小限制: ≤ 20 MB

🩺 故障排查

# 检查状态
clawpilot status

# 重启网关
clawpilot restart

# 查看日志（通过 OpenClaw / Hermes）
# OpenClaw 自修复
clawpilot doctor repair

⚙️ 配置修复

# 定位配置
ls ~/.config/openclaw/

# 检查必要字段
# - gateway_token
# - gateway_password
# - OPENCLAW_TOKEN (env)

# 验证环境变量
echo $OPENCLAW_TOKEN
